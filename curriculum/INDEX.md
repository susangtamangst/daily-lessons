# Daily Curriculum Index

This repository contains a **728-day / 104-week** FAANG-oriented SRE and Platform Engineering program.

## How to use it

Study 1–2 hours per day. Do not rush ahead just because a command worked. Each week intentionally repeats the same engineering loop:

**learn → build → inspect → break → automate → interview → review**

The detailed curriculum is grouped by year and week. Daily lesson files will live under:

```text
curriculum/
├── year-1/
│   ├── week-01/
│   ├── week-02/
│   └── ...
└── year-2/
    ├── week-53/
    └── ...
```

## Day numbering

- Year 1: Days 1–364
- Year 2: Days 365–728

## Weekly lesson format

Every lesson should include:

1. **Goal** — what capability you should gain.
2. **Why it matters** — connection to SRE/Platform/FAANG work.
3. **Mental model** — architecture and concepts.
4. **Hands-on lab** — commands/code/configuration.
5. **Failure exercise** — realistic break/fix scenario when applicable.
6. **Evidence checklist** — what to inspect before changing anything.
7. **Interview prompt** — practice explaining the topic out loud.
8. **Knowledge check** — concise questions without relying on notes.
9. **Definition of done** — observable completion criteria.

## Portfolio evidence

As the curriculum progresses, keep useful artifacts in the companion platform project:

- application code
- Dockerfiles
- Kubernetes manifests
- Terraform
- CI/CD workflows
- dashboards
- runbooks
- architecture diagrams
- incident reports
- postmortems
- system-design notes

The end goal is evidence of engineering judgment, not a pile of certificates.
