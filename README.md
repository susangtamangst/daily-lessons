# FAANG Platform Lab — Daily Lessons

A two-year, job-focused SRE / Platform / Infrastructure Engineering curriculum built around one evolving hands-on project.

The curriculum combines Python, Linux, networking, containers, Kubernetes, troubleshooting, observability, GitOps, Terraform, AWS/EKS, distributed systems, AI infrastructure, system design, and interview preparation.

The goal is not to memorize tools. The goal is to become able to **build, operate, diagnose, recover, and explain** production-like systems.

See `ROADMAP.md` and `curriculum/INDEX.md` once the curriculum is populated.
